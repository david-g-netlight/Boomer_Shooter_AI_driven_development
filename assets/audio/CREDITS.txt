Audio credits
=============

All files in this folder are PLACEHOLDERS generated by tools/generate_placeholder_audio.py
(synthesized tones, no third-party material). Re-run the script to regenerate them.

To use real assets, drop files in with the same names. The original game jam build used:
  - "Nightmares Inn" - RKVC Rod Kim, rodkim.com, @rodkim   (menu theme)
  - "Owls" - @LishGrooves                                  (gameplay theme)
Check each track's license before adding it to this repository.
